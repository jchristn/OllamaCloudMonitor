# Internationalization

English is the source and fallback locale. Spanish, Japanese, and Arabic ship as initial translations. Technical identifiers (model names, URLs, HTTP methods, JSON keys, API operation identifiers, product names, versions, and UTC) are intentionally unchanged. Native language names are defined in the locale registry. Additional recommended languages can be added without changing page logic.

`dashboard/src/i18n/index.js` owns locale metadata, direction, detection and persistence. `resources.json` holds the shared translation catalogs. Messages use i18next interpolation (`{{amount}}`, `{{seconds}}`); never concatenate translated fragments around grammatical variables. Labels, accessible names, status messages and errors use the same catalogs. Stable server error codes are mapped in the client; upstream error bodies are not displayed.

The preference order is explicit selection, the persisted `monitor.locale` value, browser language, then English. No profile preference exists. Catalogs are bundled so the selected language can be applied before the first render without a loading flash. The current small catalog does not need a separate network load; split it by namespace if its size grows.

To add a locale, add its complete catalog and registry entry, including `dir: 'rtl'` where needed. Run `npm test --prefix dashboard` for key and interpolation parity; `npm run check:i18n --prefix dashboard` also detects literal translation calls, orphaned keys, and hard-coded JSX text outside approved brand/technical identifiers. Browser tests cover persistence, English, Spanish, Japanese, Arabic, expansion (`en-XA`) and bidi (`ar-XB`). Locale-aware numbers, percentages, currencies and UTC dates use Intl with an explicit active locale. The glossary uses “usage” for consumed activity, “balance” for currently available credit, “included” for plan allowance, and “purchased” for unexpired bought credits.

The initial translations are authored for this release and should receive native-speaker review before broader distribution.
